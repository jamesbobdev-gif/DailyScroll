## README introduction

# Daily Scroll

Your social platforms, together in one Windows app.

Daily Scroll lets you choose YouTube, Instagram, TikTok, Facebook, Twitch, or Snapchat and browse its official website inside a single app window. A persistent sidebar keeps navigation and your elapsed browsing timer in reach. Select **All apps** to return to the platform picker.

**Status: experimental Windows preview.** Testing mode currently disables daily schedules and time limits. Some providers restrict embedded-browser sign-in, and full platform compatibility is still being tested. Android and iPhone versions are development projects, not published mobile releases.

## Getting started

For a published Windows preview, download its installer from the repository's Releases section. A Windows release has not yet been verified or published in this preparation workflow. Developers can follow the source setup instructions in README.md.

## Privacy and accounts

The Windows app stores website sessions in a local browser profile separate from Chrome. Sign in only through each platform's official page. Optional provider connections and the development web service require additional security work before public hosting. See RELEASE-NOTES.md for the current release gaps.
